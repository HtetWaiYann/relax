First launch on macOS

RELAX isn't notarized, so macOS blocks it the first time you open it. After moving it to Applications, run this once in Terminal:

xattr -cr /Applications/RELAX.app

What it does

Plays while it downloads
Pick a movie or episode and it starts in seconds. No waiting for the whole file.
Handles Dolby and DTS audio
Soundtracks your browser can't play are converted on the fly, so every file has sound.
Finds subtitles for you
Uses subtitles inside the file or torrent, or fetches them online, with timing you can adjust.
Picks up where you left off
Continue watching any movie or episode from the exact second you stopped.
